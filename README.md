WriteAway ✍️
A lightweight blogging platform built with Flask


📖 About
WriteAway is a simple blogging/writing platform that lets users create, edit, and publish articles in a clean,
distraction-free environment.
Built with Python (Flask), it’s lightweight, modular, and easy to deploy —
For personal blogs or as a starting point for more advanced CMS projects.

✨ Features

🔐 User Authentication — Register, login, and manage your account
📝 Article Management — Create, edit, and delete blog posts
🎨 Clean UI — Minimal, distraction-free writing experience
🧩 Flask-based Architecture — Clear and extensible project structure
🚀 Deploy Ready — Easily host on any server that supports Python

🛠 Tech Stack

Backend: Python, Flask
Frontend: HTML, CSS, Jinja2 templates
Database: SQLite (default, can be replaced with MySQL/Postgres)
Other: Werkzeug, Flask-Login, Bcrypt, itsdangerous etc.
